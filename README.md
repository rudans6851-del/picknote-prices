# picknote-prices

픽노트(getpicknote.com)에 소개한 국내 숙소 **72곳의 1박 참고가**를 사이트가 자동으로 읽어 가도록 모아 둔 공개 JSON 데이터입니다.

- 파일: [`prices.json`](./prices.json) — 사이트는 아래 주소에서 이 파일 하나만 읽습니다.
  `https://raw.githubusercontent.com/rudans6851-del/picknote-prices/main/prices.json`
- 값은 **여기어때 공개 페이지에 비로그인 방문자에게 표시되는 평일 판매가**(객실 `salePrice`)를 기준으로, 기준일(화~수 1박) 하루 전후로 갱신합니다.
- 실제 투숙일 요금·잔여 객실은 예약처에서 달라질 수 있습니다. 이 파일은 참고가 안내용이며 예약·결제와 무관합니다.

## 형식

```json
{
  "updatedAt": "2026-11-17T11:08:58+09:00",
  "targetCheckIn": "2026-11-24",
  "targetCheckOut": "2026-11-25",
  "basis": "여기어때 평일 공개 판매가(비로그인 방문자 표시가) 기준",
  "stays": {
    "<숙소 id>": {
      "base": 280000,
      "checkedAt": "2026-11-16",
      "priceBasis": "조회 기준 문구",
      "room": "소개 객실명",
      "sourceUrl": "https://www.yeogi.com/domestic-accommodations/..."
    }
  }
}
```

- `base`는 사이트가 표시하는 1박 참고가(원)입니다.
- 매진·조회 실패·객실명 불일치인 숙소는 **직전 값을 그대로 두고** `checkedAt`을 바꾸지 않습니다. 그래서 일부 항목의 날짜가 최신보다 이를 수 있습니다.

## 담긴 정보

숙소 이름·객실명·공개 요금·여기어때 공개 페이지 주소만 있습니다. 개인정보, 계정 정보, API 키, 결제 정보, 제휴 링크는 **없습니다**. 값은 공개 페이지에서 누구나 볼 수 있는 가격이며, 이 저장소는 그 값을 사이트가 읽기 쉽게 정리한 것입니다.

## 갱신

`update_prices.py`(비공개 로컬 작업 폴더)가 매일 1회 조회해 이 파일을 커밋·푸시합니다. 수동으로 고쳐도 사이트에는 다음 갱신 때 반영됩니다.
